# Как получить API-ключи Telegram

Нужны `api_id` и `api_hash` приложения. Токен обычного бота от BotFather их не заменяет.
Пользуйтесь своим аккаунтом; чужие ключи из интернета не нужны.

## Если ключей ещё нет

1. Откройте [my.telegram.org](https://my.telegram.org).
2. Введите номер своего аккаунта. Код придёт в Telegram, не по SMS.
3. Откройте **API development tools**. Если приложение уже есть, используйте его:
   по официальной инструкции на один номер приходится один `api_id`.
4. Заполните форму: название приложения, короткое имя, платформу и описание задачи.
   Например, название `PersonalAssistant`, короткое имя `PersonalAssistant`,
   описание «Personal assistant for reading selected chats and sending approved messages».
   Пример не задаёт обязательных требований к форме. URL для этого сценария не нужен.
5. После успешного создания сохраните `api_id` и `api_hash` локально через мастер:

```text
python scripts/setup_telegram.py setup
```

Эта команда выполняется из папки установленного скилла в своём терминале.
Не вставляйте ключи, код входа и пароль в переписку с ассистентом.

## Если при создании приложения появляется ERROR

Точную причину по слову ERROR определить нельзя. По опыту пользователей результат
может зависеть от подключения. Один из способов — отключить сервис, меняющий внешний
IP, и вручную задать адрес сайта в системном файле `hosts`.

Это возможный обход конкретной проблемы подключения, а не исправление всех ошибок
Telegram. Совпадение страны IP и номера не подтверждено как обязательное условие.
Сама запись hosts внешний IP не меняет и прокси не отключает.

Вариант ниже использует `149.154.167.220`: HTTPS-запрос к нему проверен 21.10.2026.
Адрес может измениться. Существующие строки файла оставьте как есть; перед правкой
сохраните его копию. Если запись для my.telegram.org уже есть, не добавляйте ещё одну:
сначала проверьте её. Не отключайте проверку HTTPS-сертификата, если браузер пожалуется.

### Windows

1. Нажмите «Пуск», напишите «Блокнот». Правой кнопкой по приложению →
   «Запуск от имени администратора». Подтвердите запуск.
2. В Блокноте нажмите **Ctrl + O**. В поле «Имя файла» вставьте путь целиком
   и нажмите «Открыть»:

```text
C:\Windows\System32\drivers\etc\hosts
```

3. Нажмите **Ctrl + End**, затем **Enter**. Вставьте на новой строке:

```text
149.154.167.220 my.telegram.org
```

4. Нажмите **Ctrl + S**, закройте Блокнот. Не создавайте отдельный `hosts.txt`.

### Mac

1. Нажмите **Command + пробел**, напишите «Терминал» и нажмите Enter.
2. Вставьте команду и нажмите Enter:

```text
sudo nano /etc/hosts
```

3. Если появится `Password`, введите пароль администратора Mac и нажмите Enter.
   Букв и звёздочек при вводе не видно — это нормально. Это пароль локального
   администратора, не пароль Apple Account.
4. Стрелкой вниз перейдите к последней строке. Нажмите **Control + E**, затем
   **Enter**, чтобы создать новую строку. Вставьте:

```text
149.154.167.220 my.telegram.org
```

5. Нажмите **Control + O** — латинскую букву O, не ноль. Затем **Enter** для
   сохранения и **Control + X** для выхода. Здесь Control, не Command.
   Надпись Pico вместо Nano в редакторе некоторых версий macOS — нормальна.

### После правки

Полностью закройте браузер и откройте заново; на Mac для полного выхода —
**Command + Q**. Попробуйте создать приложение на my.telegram.org.
При необходимости проверьте после перезагрузки компьютера: закрытие браузера
не всегда сбрасывает кэш системы. Некоторые прокси разрешают имена самостоятельно
и могут не учитывать локальный hosts.

Для отмены откройте тот же файл и удалите только добавленную строку. Если способ
не помог, не меняйте запись на случайные IP и не повторяйте создание десятки раз.
Можно попробовать другое подключение, инкогнито или браузер без расширений.
Простые названия латиницей и содержательное описание — дополнительные эмпирические
советы, не опубликованный список требований Telegram.
