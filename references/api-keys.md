# Как получить API-ключи Telegram

Нужны `api_id` и `api_hash` вашего приложения. Токен BotFather их не заменяет.
Ключи, код входа и пароль вводятся только локально, не в переписке с ассистентом.

## Сначала — порядок подключения

**На время получения ключей на my.telegram.org отключите VPN.** Запись в hosts
сама его не отключает. Оставьте прямое подключение до успешного создания приложения.
Это относится к сайту регистрации. Для дальнейшего входа через мастер и работы
скилла используйте подключение, на котором доступен Telegram: постоянно держать
VPN выключенным не требуется.

Точную причину ERROR по одному слову определить нельзя. Проверки страны номера и IP
обсуждаются как версия, но обязательное совпадение стран официально не установлено.
Если сайт открывается напрямую, сначала попробуйте создать приложение без правки hosts.
Если без прямого адреса до сайта не добраться — ниже есть отдельный способ.

## Получение ключей: куда нажимать и что делать дальше

До открытия формы ассистент должен дать и пример заполнения, и следующую команду.
Пользователю не нужно самостоятельно догадываться, куда потом вставлять ключи.

1. Откройте [my.telegram.org](https://my.telegram.org), введите свой номер.
   Код входа на этот сайт придёт в Telegram, не по SMS.
2. Откройте **API development tools**. Если приложение уже есть, используйте его:
   по официальной инструкции на один номер приходится один `api_id`.
3. Пример заполнения:

   | Поле | Пример |
   |---|---|
   | App title | `PersonalAssistant` |
   | Short name | `PersonalAssistant` |
   | Platform | `Desktop` |
   | URL | оставить пустым |
   | Description | `Personal assistant for reading selected chats and sending approved messages` |

   В примере нет слова Telegram в названии; короткое имя укладывается в 5–32
   латинские буквы и цифры. Это практичный пример, не единственный допустимый набор.
   Если форма показывает более точное требование, следуйте подсказке самой формы.
4. После создания появятся `api_id` и `api_hash`. **Не присылайте их в чат.**
   В обычном терминале из папки скилла запустите мастер:

   macOS/Linux:
   ```bash
   .venv/bin/python scripts/setup_telegram.py setup
   ```

   Windows, обычный PowerShell:
   ```powershell
   .\.venv\Scripts\python.exe scripts/setup_telegram.py setup
   ```

   Ассистент подставляет точный путь к установленному скиллу, если текущая папка другая.
5. Введите ключи по запросу мастера. **api_hash не отображается при вводе.**
   Вставьте его один раз (в Windows можно правой кнопкой мыши) и нажмите Enter.
   Мастер проверит 32 символа 0–9/a–f до подключения и предложит повторить ввод при ошибке.

## Если нужен прямой адрес: hosts

`149.154.167.220` относится к сети Telegram. Это рабочий альтернативный адрес:
21.10.2026 HTTPS-запрос к нему получил ответ сайта с корректной проверкой сертификата.
Публичные DNS в момент проверки возвращали также `149.154.167.99`; фиксированный IP
может со временем меняться. В браузере по-прежнему открывайте my.telegram.org по HTTPS.
Не отключайте проверку сертификата, если браузер пожалуется.

Запись в hosts закрепляет адрес для компьютера, минуя обычный поиск через DNS.
Она может помочь при проблемах с разрешением имени или доступом к обычному адресу,
но не исправляет все причины ERROR и не доказывает блокировку конкретным ведомством.

Помощник работает только с `my.telegram.org`: сначала проверяет существующие записи,
не создаёт дубликатов, не заменяет другой адрес молча. Перед добавлением делает
`hosts.backup-telegram` рядом с hosts; существующую первую копию не перезаписывает.
После команды очищает системный DNS-кэш. Ошибку очистки сообщает отдельно.

**Ассистент не запускает add/remove без разрешения.** По умолчанию он показывает
команду, которую пользователь выполняет сам в своём терминале. Команда status —
только чтение и не требует повышения прав:

```text
python scripts/hosts_telegram.py status
```

### Windows: одна команда для правки

1. «Пуск» → PowerShell → правой кнопкой → **«Запуск от имени администратора»**.
2. Перейдите в папку установленного скилла. Для стандартной установки Claude Code:

```powershell
Set-Location "$HOME/.claude/skills/telegram"
```

Для Codex используйте `.codex` вместо `.claude`. Если скилл установлен в другое место,
используйте его полный путь. Затем выполните одну команду:

```powershell
.\.venv\Scripts\python.exe scripts/hosts_telegram.py add
```

3. **Закройте администраторское окно. Мастер setup запускайте в обычном PowerShell.**
   Создание ключей и вход не требуют прав администратора; мастер остановится при
   повышенных правах, чтобы не сохранить данные под неожиданным владельцем.

### Mac: одна команда для правки

Откройте «Терминал» и перейдите в папку установленного скилла. Стандартный путь
Claude Code — `~/.claude/skills/telegram`, Codex — `~/.codex/skills/telegram`.
Из этой папки выполните:

```bash
sudo .venv/bin/python scripts/hosts_telegram.py add
```

Введите пароль локального администратора Mac. Ни букв, ни звёздочек при вводе
не видно — это нормально. Затем запускайте мастер обычной командой, **без sudo**.

Если предпочитаете ручное редактирование, файл можно открыть через
`sudo nano /etc/hosts`: в конец добавить `149.154.167.220 my.telegram.org`,
сохранить Control+O, Enter, выйти Control+X. После ручной правки выполните команды
очистки DNS из [диагностики](troubleshooting.md).

### Откат

В том же окружении и с теми же правами выполните `hosts_telegram.py remove`
вместо `hosts_telegram.py add`. Удаляется только блок, добавленный помощником;
чужие и более поздние настройки сохраняются. Резервная копия остаётся.
Запись, внесённую вручную, помощник не удаляет: уберите только эту строку вручную.

## После правки сайт всё равно не открывается

Системный DNS и браузер могут сохранять старое состояние подключения. Полностью
закройте браузер и откройте снова; на Mac для полного выхода — Command+Q.
Если не помогло, попробуйте другой браузер с тем же подключением, всё ещё без VPN.
Не повторяйте правку hosts много раз: сначала пройдите [диагностику](troubleshooting.md).

hosts в автотестах не меняется. Универсальный успех регистрации не заявляется.
