# Changelog

## [1.1.0] — 2026-10-21

### Added
- Отправка локального файла документом: карточка вложения, подпись и проверка контрольной суммы.
- Помощник настройки адреса сайта: проверка, резервная копия, защита от дубликатов и откат своего блока.
- Диагностика подключения и пошаговая очистка сохранённых адресов для Windows и Mac.

### Changed
- Мастер останавливается при запуске с повышенными правами до сохранения данных.
- Формат ключей проверяется локально с повторным вводом и понятным сообщением об ошибке.
- Инструкция заранее объясняет заполнение формы и безопасный локальный ввод ключей.

## [1.0.1] — 2026-10-21

### Changed
- README сосредоточен на установке и использовании скилла.
- Обновлены ссылка на Telegram-канал и оформление раздела об авторе.

## [1.0.0] — 2026-10-21

### Added
- Самостоятельная установка Telegram-скилла для Claude Code и Codex.
- Локальный мастер: получение API-ключей, вход в аккаунт и проверка подключения.
- Пошаговая помощь при ERROR на my.telegram.org для Windows и Mac.
- Локальное сохранение ключей, совместимость с переменными окружения и macOS Keychain.
- Автоматические проверки настройки и предохранителя отправки.

### Preserved
- Поиск чатов и чтение сообщений без отправки.
- Сухой прогон с точным адресатом и текстом перед согласованной отправкой.
